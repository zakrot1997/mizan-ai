# ميزان AI — مكتب الأعمال الذكي

نظام إدارة أعمال ومشاريع يعمل **داخل المتصفح** كنافذة مستقلة، يقوده **وكيل ذكاء اصطناعي** يدير بياناتك **ويتحكم في متصفح مدمج** (يفتح الروابط، يقرأ الصفحات، يلخص المحتوى) — وأنت تتحدث معه بالعربية.

---

## القدرات

| القسم | الوصف |
|---|---|
| **الوكيل الذكي** | محادثة عربية تُنشئ المشاريع والمهام والمعاملات والتقارير بنفسها، مع بثّ مباشر للرد وشارات لكل إجراء ينفذه |
| **المتصفح المدمج** | نافذة ويب حقيقية داخل البرنامج: شريط عنوان ذكي، مفضلة، سجل تنقل، «وضع قراءة» يتجاوز حظر التضمين، والوكيل يقوده أمام عينيك |
| **المشاريع وكانبان** | بطاقات مشاريع بحلقات تقدم وميزانيات، ولوحة مهام بسحبٍ وإفلات حقيقي عبر 5 أعمدة |
| **المالية** | إيرادات/مصروفات، رصيد، تدفق شهري بياني، فئات صرف، وربط المصروفات بالمشاريع تلقائياً |
| **العملاء والملاحظات** | ملفات عملاء كاملة + ملاحظات + تقارير يولّدها الوكيل ويحفظها تلقائياً |
| **لوحة الأوامر** | `Ctrl+K` للوصول الفوري لأي قسم أو إجراء |

## ثلاثة محركات ذكاء — بدّل بينها من داخل البرنامج

1. **سحابي (مفاتيح API):** أي مزود متوافق مع OpenAI — OpenAI، OpenRouter، Groq، Google Gemini… والمفتاح يُخزَّن في خادمك فقط.
2. **خادم محلي llama.cpp (موصى به لجهازك):** البرنامج نفسه يشغّل ويوقف `llama-server` ويعرض حالته وسجلاته من الإعدادات.
3. **داخل المتصفح (wllama):** النموذج نفسه يعمل على WebAssembly بلا أي خادم ولا تثبيت — خصوصية مطلقة.

## التشغيل السريع

<div dir="ltr">

```bash
npm install
docker compose up -d          # قاعدة PostgreSQL (أو استخدم قاعدتك الخاصة)
cp .env.example .env
npx drizzle-kit push          # إنشاء الجداول
npm run dev                   # أو: npm run build && npm run start
```

</div>

ثم افتح `http://localhost:3000` — ناول الوكيل من الزرّ البنفسجي، وجرّب: *«أنشئ مشروع متجر إلكتروني بميزانية 50000 وأضف له ثلاث مهام»*.

### نافذة مستقلة (تطبيق حقيقي)
من Chrome/Edge: قائمة ⋮ ← **حفظ وتثبيت / Install Mizan** — سيعمل كتطبيق مستقل بأيقونته بجوار برامجك، ويمكن تثبيته في شريط المهام وجدولة تشغيل الخادم مع بدء ويندوز (Task Scheduler: `npm run start`).

## تشغيل نموذجك LFM3-1.7B-Q5_K_M.gguf على جهازك

مواصفاتك (`i7-3770 · 12GB RAM · RX 580 8GB`) مناسبة تماماً — النموذج Q5_K_M بحجم ≈1.2GB ويعمل على المعالج بسرعة مقبولة (≈6–12 رمزاً/ث) مع إمكانية تسريع Vulkan لبطاقة AMD.

### الطريقة 1 — الخادم المحلي (الأسرع، موصى بها)

<div dir="ltr">

```bat
:: ويندوز — نقرة مزدوجة تكفي مع setup-local-ai.bat، ومن الطرفية:
scripts\setup-local-ai.bat
:: تسريع بطاقة RX 580 (Vulkan):
scripts\setup-local-ai.bat --vulkan
```

</div>

ثم:
1. حمّل النموذج من Hugging Face (ابحث: `LFM3 1.7B GGUF`) وضعه في مجلد `models/` باسم `LFM3-1.7B-Q5_K_M.gguf`
2. من البرنامج: **الإعدادات ← الخادم المحلي ← تشغيل المحرك** — سيظهر «يعمل وجاهز»
3. بدّل المحرك إلى **خادم محلي** وتحدث مع الوكيل

### الطريقة 2 — داخل المتصفح مباشرة (بلا تثبيت)
الإعدادات ← **النموذج داخل المتصفح** ← اختر ملف GGUF — يُحمّل على WebAssembly ويبقى مخزَّناً في متصفحك. أبطأ لكنه يعمل حتى بلا خادم.

## البنية

<div dir="ltr">

```
src/
├─ db/schema.ts             # المشاريع، المهام، المعاملات، العملاء، الملاحظات، الإعدادات
├─ lib/ai/                  # نظام الأدوات + بروتوكول الوكيل + منفّذات قاعدة البيانات
├─ lib/agent/               # محرك wllama داخل المتصفح + أدواته
├─ app/api/chat             # حلقة الوكيل (بث SSE، استدعاء أدوات متعدد الجولات)
├─ app/api/local-ai         # تشغيل/إيقاف/مراقبة llama-server من الواجهة
├─ app/api/proxy            # قارئ الصفحات الآمن (يتجاوز CORS)
└─ components/              # سطح مكتب كامل: شريط عنوان، شريط جانبي، وكيل، 8 أقسام
```

</div>

## أمان
- مفاتيح API لا تغادر الخادم أبداً (تُعاد مُقنَّعة للواجهة).
- قارئ الصفحات يحظر العناوين الداخلية افتراضياً (SSR-F protection).
- النموذج المحلي: بياناتك لا تغادر جهازك إطلاقاً.
